# Matemaatikamaa

Tasuta eestikeelne 1.–3. klassi peastarvutamise veebirakendus.

## GitHub Pagesis avaldamine
1. Loo GitHubis uus **public** repository nimega `matemaatikamaa`.
2. Laadi `index.html` repository juurkausta (Add file → Upload files → Commit changes).
3. Ava **Settings → Pages**.
4. Vali **Build and deployment → Deploy from a branch**, haruks **main** ja kaustaks **/(root)**. Salvesta.
5. Pärast avaldamist on leht tavaliselt aadressil `https://SINU-KASUTAJANIMI.github.io/matemaatikamaa/`.

## Märkused
- Rakendus töötab ilma serveri ja kontodeta.
- Parim tulemus salvestatakse brauseri localStorage'isse.
- Võistlusaja arvestus käib brauseris; see ei sobi veel ametlikuks võistluseks.
- Klassi ja tehete valik on vabalt kombineeritav, ka 1. klassi korrutamine/jagamine.
